Project Lady / Home Flow v1.6
2026-08-11

基盤
- v1.5 Navigation v0.1 全画面リロード復帰修正版

今回の工事
- 「これから考える」を選んだ旅では、Homeに「何から考える？」を主導線として表示
- 「旅先を考える」入口を交通の中に隠さず、Homeから直接入れるように変更
- 交通カードは残し、利用者が自分で交通を選んだ場合は交通画面をそのまま開く
- 行き先未定だからといって交通へ強制分岐しない
- 「旅先を考える」を「旅のことを考える」に変更し、旅先を決める前提も弱めた
- 内輪の修正理由だった「先に交通を決めなくても大丈夫」を削除
- 画面コピーを「まだ決まっていなくて、大丈夫。／何から考える？」へ整理

レビュー重点
1. 「これから考える」選択後、Homeで「何から考える？」が自然に見つかるか
2. 「何から考える？」から「旅のことを考える」へ入れるか
3. Homeの「交通」を押した場合、勝手に別画面へ飛ばず交通画面が開くか
4. PC / Pixelで主導線が大きすぎず、既存Homeの静けさを壊していないか
5. リロード復帰などv1.5の既存機能が壊れていないか
