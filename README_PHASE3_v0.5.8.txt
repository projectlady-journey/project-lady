Project Lady Phase3 v0.5.8

旅の管理UX改善版。

・「旅の管理」に現在の旅と保存している旅を分けて表示
・保存旅の削除ボタンと、旅名を示す確認画面を追加
・日程確定旅は開始日の早い順、日程未定旅は初回保存の古い順に表示
・初回保存日時 savedAt を再保存後も保持
・Homeで旅タイトル・出発日・帰着日・行き先を編集可能
・保存旅件数をボタン文言へ統合
・各機能画面の戻る操作を「旅のHomeへ」と明記
・旅のHomeの役割を初回のみ案内
・交通の移動手段に「車」を追加（レンタカーとは別枠）

既存の projectLadyJourneyRegistry_v01 をそのまま引き継ぐ。
