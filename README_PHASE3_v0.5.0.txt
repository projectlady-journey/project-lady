Project Lady Phase3 / v0.5.0 旅ライフサイクル基盤

今回の主目的
- v0.4.3の「1ブラウザ=1旅」から、複数の旅を扱える基盤へ移行。
- 既存の大阪・紀南旅は、旧Journey Boxから自動で「現在の旅」へ移行して保持。
- 新しいブラウザでは大阪・紀南のサンプルを自動注入せず、完全な空の旅から開始。

追加
- Journey Registry: currentJourney / savedJourneys / completedJourneys
- Homeに「保存した旅」「最初からやり直す」入口
- 「最初からやり直す」時に
  1) 保存して最初に戻る
  2) 保存せず最初に戻る
  3) やめる
  を選択可能
- 保存した旅一覧から「この旅を再開」可能
- 再開時、現在の旅に意味のある入力があれば自動的に保存側へ退避
- 意図的に白紙化した後、旧大阪・紀南データが復活しないよう旧単一Journey Boxキーを除去

まだ後工程
- 終了済み旅→思い出BOX（仮）のUI
- 旅タイトル・日付・行き先の一般ユーザー向け編集
- 旅程 / Memo / 持ちもの / 旅ログの本実装
- 宿泊保険予約のブルーカードと取消期限UI

確認
- JS構文チェック済み
- 新規ブラウザ=空旅、v0.4.3移行、保存→白紙、保存旅再開、破棄後の非復活をロジックテスト済み
